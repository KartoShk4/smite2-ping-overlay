SMITE 2 Ping — плашка с пингом для Windows (портативная версия)
=================================================================

Ничего устанавливать не нужно: работает на обычной Windows 10/11
через встроенный PowerShell.

Запуск
  Двойной клик по «Запуск.bat». Программа уходит в фон,
  в трее у часов появляется значок (чёрный кружок с зелёной точкой).

Управление
  F8 — показать/скрыть плашку.
  Плашку можно таскать мышкой, место запоминается.
  Плашка видна только когда активно окно SMITE 2. Если свернуть игру
  или переключиться в другое окно, она прячется.
  Выход: правый клик по значку в трее, «Выход».

Что пишет плашка
  Ping: N ms        — пинг (зелёный < 60, жёлтый < 120, красный больше)
  нет матча         — игра не подключена к серверу
  оффлайн-режим     — тренировка/оффлайн
  ищу маршрут…      — первые секунды после входа на новый сервер
  нет ответа        — сервер перестал отвечать
  нет лога игры     — не найден лог игры

Как считается пинг
  Сервер берётся из лога игры:
  %LOCALAPPDATA%\SMITE2Alpha\Saved\Logs\Hemingway.log
  Серверы Azure не отвечают на ping, поэтому пингуется последний
  отвечающий узел сети перед сервером. Это почти то же самое.

Если не запускается
  * Windows может спросить «Защитник Windows/SmartScreen»:
    нажмите «Подробнее» → «Выполнить в любом случае».
  * Антивирус может ругаться на скрипт, который ловит клавишу F8.
    Это нормально, скрипт открытый, его можно прочитать в Блокноте.
  * Плашка не видна поверх игры в режиме «Полный экран».
    Поставьте в игре «Оконный без рамки» (Borderless).
  * Ошибки пишутся в файл %TEMP%\smite2_ping_error.log

Автозапуск (по желанию)
  Win+R → shell:startup → положить туда ярлык на «Запуск.bat».

Место плашки хранится в %APPDATA%\smite2_ping.json
